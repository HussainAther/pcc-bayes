# v0.5 Adaptive-exploiter and independent-architecture freeze

Date frozen: 2026-08-25

## Question

Does the mature PCC Chaos result survive both (a) an exploiter that updates online as actions are observed and (b) a second, independently specified value-aware stochastic policy architecture?

This experiment is frozen before the v0.5 confirmatory results are inspected.

## Environment

Reuse the v0.4.1 binary Markov tracking task without changing its parameters:

- steps per episode: 400
- hidden-state switch probability: 0.08
- observation accuracy: 0.75
- calibration seeds: 0--49
- evaluation seeds: 1000--1099

The hidden state remains unavailable to the exploiter. Public observations and prior public actions are available.

## Policies

1. `predictable_value`: deterministic MAP/value baseline.
2. `uniform_random`: anti-definition baseline.
3. `structured_chaos`: the unchanged v0.4.1 confidence-dependent mixing policy.
4. `threshold_chaos`: independent architecture. At each decision a fresh threshold is sampled uniformly from [0.25, 0.75]; action 1 is selected iff the current posterior probability of state 1 exceeds that threshold. Thus behavior is deterministic outside the threshold interval and stochastic inside it. No coefficients are fit to the confirmatory results.

The threshold architecture is intentionally distinct from the v0.4.1 policy: stochasticity is generated by a sampled decision criterion rather than by directly assigning a non-MAP action probability from confidence.

## Adaptive exploiter

Use a context table with the same public context class as the v0.4.1 diagnostic:

- current and previous public observations (`observation_order=2`)
- two previous public actions (`action_order=2`)
- Laplace/Beta smoothing `alpha=1`

Initialize the table on the 50 calibration episodes for the policy being evaluated. During evaluation, make a prequential prediction before each action and then immediately update the table with the observed action. Learned counts persist through the evaluation stream in frozen seed order.

This is a stronger test than the frozen v0.4.1 context lookup because the opponent can adapt to the candidate policy online.

## Candidate gates

Each Chaos candidate (`structured_chaos` and `threshold_chaos`) must independently satisfy all four gates:

1. **Unpredictability**: mean normalized policy entropy >= predictable-value entropy + 0.10.
2. **Adequacy vs random**: mean task accuracy >= uniform-random accuracy + 0.15.
3. **Value preservation**: mean task accuracy >= predictable-value accuracy - 0.08.
4. **Adaptive exploitability resistance**: adaptive exploiter accuracy <= predictable-value adaptive exploiter accuracy - 0.05.

## Replication criterion

The v0.5 independent-architecture replication passes only if **both** candidate policies pass all four candidate gates.

## Anti-definition checks

- Uniform random play must not be counted as mature Chaos merely because it is difficult to predict.
- Observation corruption remains a noise-channel construct and is not promoted to mature PCC Chaos in this experiment.

## Interpretation boundaries

Passing supports a narrow synthetic claim: two independently implemented value-aware stochastic policies can preserve task value while reducing online conditional exploitability in this Bayesian tracking substrate.

Passing does not establish human validity, game-theoretic equilibrium, universal PCC Chaos, or cross-domain portability.

Failure is retained without moving thresholds, seeds, environment parameters, policy coefficients, or exploiter class.
