# Contributing

PCC-Bayes is research software. Contributions should favor falsifiable models, reproducible experiments, and explicit assumptions.

1. Open an issue describing the hypothesis or failure being tested.
2. Add or update tests for reusable code.
3. Keep generated results out of source modules.
4. Document whether a probability is a true generative probability, inferred posterior, heuristic score, or simulation-matching weight.
5. Preserve negative results when they constrain the framework.
